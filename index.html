系统修复步骤

先保存正在编辑的文件并备份重要资料。命令都需要你手动复制、粘贴和确认；命令窗口必须以管理员身份打开的步骤会明确标出。

安全提醒：不要一次执行全部命令

每完成一项就等它结束、读懂结果并记录，再继续。修复过程中如果蓝屏、断电或出现无法理解的提示，请停止操作并保存截图；不要尝试删除驱动、改注册表或关闭安全功能。

01检查 Windows 版本和更新状态先确认当前版本与待安装更新⌄

操作方法

  1. 打开「开始」→「设置」→「系统」→「关于」，在「Windows 规格」中记下版本和 OS 内部版本。
  2. 回到「设置」→「Windows 更新」，查看是否有更新正在等待安装、安装失败或需要重启。
  3. 如果有更新，先保存工作并按 Windows 提示完成更新；重启后观察电脑是否还蓝屏。不要在更新过程中强制关机。

预期结果

能记下 Windows 11 版本与更新状态；更新完成后正常进入桌面。

遇到问题怎么办

更新失败时记录错误代码并截图，不要反复强制重启。可以先跳过更新操作，继续记录其他信息，稍后联系荣耀支持或可信的维修人员。

02检查 Windows 组件状态DISM CheckHealth · 通常很快完成 · 管理员权限⌄

操作方法

  1. 在「开始」按钮上点右键，选择「终端（管理员）」或「Windows PowerShell（管理员）」，在权限提示中选择「是」。
  2. 只复制下面这一条命令，粘贴到窗口中并按 Enter。等命令显示完成后再读结果。
DISM /Online /Cleanup-Image /CheckHealth

预期结果

显示「未检测到组件存储损坏」或类似健康状态，表示此项检查结束。记录完整结果。

失败时怎么办

如果提示不是管理员、命令无法识别或报告组件存储损坏，先截图并记录原文。不要输入其他命令；完成本项后再决定是否继续下一步。

03深度扫描组件存储DISM ScanHealth · 可能需要较长时间 · 管理员权限⌄

操作方法

  1. 确认上一步命令已经结束，再在同一个管理员终端中单独运行本命令。
  2. 扫描可能持续一段时间，进度看起来暂时不动也请耐心等待。接通电源，不要关闭窗口或强制关机。
DISM /Online /Cleanup-Image /ScanHealth

预期结果

结果会说明组件存储是否可修复、是否存在损坏，或未发现损坏。请记下完整文字。

失败时怎么办

遇到错误代码、进度长时间没有变化或电脑异常发热时，先拍照并记录。不要连续重复扫描；根据扫描结果再判断第四步是否适用。

04按扫描结果决定是否修复只有扫描报告可修复的损坏时才运行 · 管理员权限⌄
先看第三步的结果，再做决定

如果 ScanHealth 明确显示未发现损坏或组件存储健康，请跳过下面的修复命令，直接进行第五步。如果报告组件存储损坏且可以修复，再按以下方法操作。

操作方法

  1. 保持电脑接通电源、网络畅通，并确保 ScanHealth 已结束。
  2. 仅当扫描报告可修复的组件存储损坏时，才在管理员终端中单独运行下面的命令。修复可能需要一段时间。
DISM /Online /Cleanup-Image /RestoreHealth

预期结果

提示还原操作成功完成。记录结果，等命令完全结束后再进行第五步。

失败时怎么办

如果报告无法修复、来源文件找不到或有错误代码，请停止，不要从陌生网站下载系统文件。截取完整提示，先寻求荣耀官方支持或可信的维修人员帮助。

05检查并修复 Windows 系统文件SFC 扫描 · 可能需要一些时间 · 管理员权限⌄

操作方法

  1. 确认第四步已结束，或者第三步显示无需修复后，再单独运行本命令。
  2. 在管理员终端中输入命令，等待验证到 100% 并显示最终结果。请勿中途关闭窗口。
  3. 如果提示修复了文件，记录结果并按提示正常重启一次；重启后观察是否还蓝屏。
sfc /scannow

预期结果

可能显示未发现完整性冲突、发现并修复了损坏文件，或发现损坏但无法修复。三种结果都要记录。

失败时怎么办

如无法修复或出现错误代码，先保存结果和截图，不要反复运行命令。若蓝屏仍出现，进入下面的驱动、Hypervisor 和硬件排查并向专业人员提供记录。

显卡驱动排查

Intel 核显和 NVIDIA 独显的准确型号尚未确认。先收集信息，不要盲目卸载或替换驱动。

查看显卡型号与驱动版本

  1. 右键「开始」→「设备管理器」→展开「显示适配器」，记录 Intel 和 NVIDIA 项目的完整名称。
  2. 逐个右键设备→「属性」→「驱动程序」，记录驱动提供商、日期和版本。
  3. 也可以在「任务管理器」→「性能」中查看 GPU 名称。遇到感叹号时截图记录。

设备管理器里可选择「回滚驱动程序」等操作；先不要点击任何更改按钮。

优先核对荣耀官方驱动

先从荣耀官方网站的驱动下载页按笔记本准确型号查找 Windows 11 驱动，核对版本、发布日期和适用机型。型号不确定时先查看电脑底部标签或「设置 → 系统 → 关于」。

Hypervisor 与虚拟化安全排查

0x00020001 是蓝屏报告中的错误代码，单凭代码无法确认根因。先读取当前设置和状态，不要为了尝试修复而关闭安全功能。

查看 Hyper-V 功能状态

  1. 在开始菜单搜索「启用或关闭 Windows 功能」，打开窗口后只查看状态。
  2. 记录「Hyper-V」「虚拟机平台」「Windows 虚拟机监控程序平台」是否勾选，然后关闭窗口。
  3. 请不要勾选或取消勾选任何项目；更改可能影响虚拟机、模拟器或安全功能。

查看 VBS 与内存完整性

  1. 按开始菜单搜索「系统信息」，查看「基于虚拟化的安全性」状态并记录。
  2. 打开「Windows 安全中心」→「设备安全性」→「核心隔离详细信息」，只查看「内存完整性」当前开/关状态。
  3. 不要直接关闭内存完整性或其他 Windows 安全功能。如果页面提示冲突驱动，记录驱动名称并先核实来源。
遇到安全设置变更建议，先暂停

关闭 Hyper-V、VBS 或内存完整性会降低防护或影响依赖虚拟化的软件。只有确认具体原因、理解影响并得到可靠指导后，才考虑调整。

无需拆机的初步检查

硬件检查清单

硬件信息先读取和记录。若出现异响、异味、异常高温或反复蓝屏，请保存资料后停止高负载使用并联系官方维修。

SSD 健康状态

打开「设置 → 系统 → 存储 → 高级存储设置 → 磁盘和卷」，选择磁盘查看「属性」中的健康状态（若系统提供此项）。也可用荣耀官方诊断工具检查。出现预警或读写异常时，优先备份重要文件并联系维修。

内存稳定性

如果需要，可在开始菜单搜索「Windows 内存诊断」并按提示安排检查。此操作会重启电脑；先保存并关闭所有工作，接通电源。若不确定或电脑频繁蓝屏，先让维修人员协助。

CPU 温度与散热

使用荣耀官方诊断/管家中可用的硬件检测功能。保证笔记本放在坚硬平整的表面，出风口不被遮挡。不要为了测温运行压力测试或拆机；持续高温、风扇异响请停止高负载任务。

BIOS 版本

在开始菜单搜索「系统信息」，记录「BIOS 版本/日期」和电脑完整型号。此处只记录版本；不要因为有新版本就自行升级 BIOS。BIOS 更新中断可能导致电脑无法启动，请先咨询荣耀官方支持。
